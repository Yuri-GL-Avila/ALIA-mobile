# ALIA — Alerta Inteligente de Apoio

Protótipo mobile (React Native + Expo + TypeScript) de proteção feminina.

## Funcionalidades

- SOS com long-press (~1,2s)
- Check-in de segurança (5 / 15 / 30 min)
- Lugares seguros
- Rede de contatos de confiança
- Linha do tempo da ocorrência
- Central de atendimento (aceitar estilo Uber)
- Dispositivo físico (BLE simulado)
- Histórico, privacidade e canais 180/190

## Como rodar no VS Code

```bash
cd alia-mobile
npm install
npx expo start
```

Depois abra no Expo Go (celular) ou emulador.

Demonstração local: Bluetooth, GPS real e fila entre aparelhos diferentes ainda não usam servidor.
